# Ujjwal Tools

`tools.ujjwaluzu.in` is a personal, local-first toolbox containing small utilities for annoying everyday, developer, web, document, image, and productivity tasks.

> Tiny tools for annoying tasks.

## Core principles

- Local-first whenever technically possible.
- Privacy by default.
- Simple, focused tools.
- Fast and lightweight.
- Consistent UI.
- Accessible and mobile-friendly.
- No unnecessary accounts.
- No unnecessary external SaaS dependencies.

## Tool contract

Every tool should have a dedicated route, clear title/description, obvious input, primary action, loading/progress state where necessary, success/error states, copy/download/export action where appropriate, responsive UI, SEO metadata, and a privacy/processing note when files are involved.

Build incrementally. Do not implement the entire roadmap at once.

See [Student Tools](STUDENT.md) for the available writing, citation, OCR, and study tools and their limitations.
